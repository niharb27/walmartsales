# walmartsales
this is my very first GitHub repo. I built a small neural network that predicts weekly sales across 45 walmart stores. (tensorflow)

hi, i've been doing the machine learning specialisation from andrew ng from coursera. i learnt about supervised learning in its first two courses. so to implement my learning i decided to make this model that predicts weekly sales for 45 walmart stores. 

well, tbh, earlier when i learned the linear regression from the first course, i implemented the same using a very very simple one degree model, which was okayish. ofc, a linear model with one degree is just a straight line and it doesnt really learn the non-linear relationships. but it was more about implementing things from scratch, ie, writing the compute cost function, gradient descent function, etc. i was able to write that in pure python and numpy. 

in the second course, i got introduced to neural networks. a big advantage of neural networks is that it is able to learn the non-linear relationships by itself without brainstorming about any polynomial features. it does that by using the activation functions (like relu) across many layers, which in the end gives the curve that only polynomial features can get.
